Eye-Tracking Dataset Description Document 
 
Introduction 
This document provides a detailed description of the eye-tracking dataset collected during 
our study. The dataset contains comprehensive recordings of participants’ eye movements 
while interacting with various stimuli, along with associated metadata, calibration and 
validation metrics, and Areas of Interest (AOIs) information. The dataset is structured to 
allow detailed analysis of gaze behavior, fixation patterns, and interaction with visual 
elements. This document is intended to help researchers and analysts understand the 
structure, content, and purpose of each column in the dataset to facilitate reproducibility, 
analysis, and interpretation.
