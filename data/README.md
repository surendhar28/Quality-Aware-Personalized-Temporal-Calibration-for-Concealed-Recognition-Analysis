# GazeGuard AI Data Provenance and Directory Specification

## Directory Roles
- `data/raw/`: Dedicated storage for raw eye-tracking datasets (e.g., Zenodo record 18525952 CIT recordings). Raw files in this directory are git-ignored to prevent inadvertent disclosure of research data.
- `data/processed/`: Standardized, anonymized canonical feature tables and audit logs generated by the ingestion pipeline.
- `data/synthetic/`: Clearly watermarked synthetic gaze datasets used exclusively for software testing, automated CI/CD pipeline verification, and offline dashboard verification when primary datasets are restricted.

## Primary Benchmark Dataset
- **Title**: Eye tracking as a Tool for deception detection with CIT
- **Persistent Identifier (DOI)**: `10.5281/zenodo.18525952`
- **Authors**: Weronika Celniak, Dominika Słapczyńska, Beata Jarszak, Piotr Augustyniak
- **Institutions**: AGH University of Krakow; Forensic Laboratory of the Police Headquarters in Katowice
- **Publication Date**: February 8, 2026
- **License**: Creative Commons Attribution 4.0 International (`CC-BY-4.0`)
- **Apparatus**: Tobii Pro Fusion desktop eye tracker (sampling rate ~60-250 Hz), 27-inch Full HD monitor
- **Cohort**: 39 participants (20 experimental guilty group, 19 innocent control group; age range 19–60, M = 28.05, SD = 9.5; 56% female, 44% male)
- **Protocol**: 4-item stimulus array (1 probe/critical item, 3 irrelevant/neutral items) presented for 7.5 seconds per trial, repeated 3 times with randomized spatial positions.

## Automated Download & Access Notice
Zenodo applies automated rate-limiting and Cloudflare bot protection (`HTTP 403 Forbidden`) on direct non-browser requests from server/agent environments. 
Researchers wishing to run experiments against the primary recording files should:
1. Navigate directly to `https://zenodo.org/records/18525952` in a compliant browser.
2. Download the desired recording files (`CIT Recording1.xlsx` through `CIT Recording40.xlsx`).
3. Place the downloaded `.xlsx` files into `data/raw/`.
4. Trigger the backend dataset audit endpoint (`POST /api/datasets/audit`) or run `python scripts/audit_dataset.py`.

When primary files are not downloaded, GazeGuard AI seamlessly activates its **Synthetic Data Mode**, providing structurally identical, schema-compliant data with explicit provenance labeling.
